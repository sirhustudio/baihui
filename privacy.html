隐私政策

百回 · 最后更新 2026 年 9 月 17 日

百回没有服务器，不在任何服务器上收集你的数据。你的书籍与划线全部保存在这台 iPhone 上，我们看不到，也无法取回。

我们收集什么

百回不在任何服务器上收集你的数据；仅当你主动发送反馈邮件时，你选择附带的诊断信息会发给开发者。百回没有账号体系，不要求注册，不接入任何统计、分析或广告 SDK，不采集设备标识符，也不会把你的阅读内容发送到我们控制的任何地方。

数据保存在哪里

API Key保存在 iPhone 的钥匙串（Keychain）

书与划线保存在 App 的本机数据库

组件内容保存在 App Group 共享容器，供桌面小组件读取

书封缩略图由 App 下载后保存在本机，供组件离线显示

体验资格体验开始时间保存在钥匙串，购买资格由 App Store 提供

API Key、书与划线、组件内容、书封缩略图和体验开始时间都保存在你的设备内，受系统钥匙串、沙盒与数据保护机制约束。购买资格由 App Store 管理，百回只在设备上读取有效资格。

App 会联网访问哪里

  • 微信读书官方接口（i.weread.qq.com）——使用你自己提供的 API Key，读取你已经划下的句子。此过程受微信读书的服务条款与隐私政策约束。
  • 书籍封面图片——从微信读书返回的图片地址下载，仅用于在 App 与组件中显示。

除此之外，百回不会向任何其他服务器发送数据。

关于问题反馈

当你在 App 内主动选择「反馈问题」时，邮件正文会附上一段诊断信息：App 版本与构建号、系统版本、设备型号标识、是否已连接微信读书、本机书籍与划线的数量、以及已添加的小组件样式。

其中不包含你的划线正文、书名、作者或 API Key。这段内容在邮件发出前完整可见，你可以删除后再发送。是否发送完全由你决定。

邮件还会默认附上本机近期的运行日志；如果百回曾经崩溃，另附崩溃报告。日志记录的是功能运行情况（如同步了多少条、耗时多久、失败原因），不含你的划线正文、书名、作者或 API Key。附件在发送前可见，你可以删除。

崩溃与诊断

百回使用开源组件在本机记录运行日志与崩溃报告，它们只保存在你的设备上，不会自动上传，只有在你主动发送反馈邮件时才会作为附件发出。

如果你在系统设置中打开了「分享 iPhone 分析」，或通过 TestFlight 参与测试，Apple 可能会把崩溃日志与使用统计提供给开发者。这部分由 Apple 采集与匿名化处理，遵循 Apple 的隐私政策，你可以随时在系统设置中关闭。

购买

百回的购买通过 Apple 的 App 内购买完成。我们不接触也不保存你的支付信息；购买凭证由 Apple 处理与校验。

删除你的数据

「断开微信读书」只会停止后续同步并删除保存的 API Key；已经带回百回的书籍、划线和小组件内容会继续保留。

如需删除阅读数据，请在「我的 → 微信读书与同步 → 清除本机阅读数据」中操作。该操作会删除这台 iPhone 中保存的 API Key、书籍、划线和小组件内容，本机的运行日志与崩溃报告也会一并删除。卸载百回也会删除本地阅读内容；重新安装后的首次启动会清理系统可能保留的旧 API Key。

为执行三日体验和恢复永久买断，体验开始时间与 App Store 购买资格不会由「清除本机阅读数据」重置。它们不包含书名、划线正文或其他阅读内容。由于我们没有服务器，没有任何需要联系我们才能删除的数据。

儿童

百回不收集任何人的个人信息，儿童也不例外。App 没有账号体系、没有社交功能、不展示广告，也不会把任何内容上传到我们这里。我们不设年龄门槛。

政策变更

如果本政策发生变化，我们会更新本页顶部的日期。涉及重大变化时，会在 App 内或小红书主页说明。

Privacy Policy — 百回 (BaiHui)
We operate no server and collect no data on any server; diagnostic information is sent to the developer only when you choose to attach it to a feedback email. Your API key is stored in the device Keychain; your books and highlights are stored only on your iPhone. Disconnecting removes the API key but keeps locally imported reading content; the separate Clear Local Reading Data action removes the key, books, highlights and widget content. A local trial-start record and App Store purchase entitlement are retained separately to provide the trial and restore purchases, and contain no reading content. The app connects only to WeChat Reading's official API using your own key, and to the book-cover image URLs it returns. No analytics, advertising or tracking SDKs are used. Feedback emails you choose to send include app version, OS version, device model, connection state and item counts — never highlight text or your API key. Local logs and crash reports stay on device and are only attached to feedback emails you choose to send. We collect no personal information from anyone, children included; the app has no accounts, no social features and no advertising.
