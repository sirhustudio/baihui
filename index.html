常见问题

怎么找到微信读书 API Key？

按 图文指引 一步步操作即可，大约一分钟。

为什么需要微信读书 API Key？

百回通过微信读书的官方接口读取你已经划下的句子。Key 只保存在你 iPhone 的钥匙串（Keychain）里，不会上传到任何服务器，也不会出现在反馈邮件中。

桌面小组件不显示内容？

请先打开一次百回，让它把最新的划线写入组件；如果刚刚完成首次同步，书封需要稍等片刻才会出现。仍有问题请把 App 版本号一并告诉我们。

断开连接会删掉我的划线吗？

不会。断开连接只会停止后续同步，并移除这台 iPhone 中保存的微信读书 API Key；已经带回百回的书籍、划线和小组件内容会继续保留。以后重新连接即可恢复同步。

怎么删除我的数据？

在「我的 → 微信读书与同步 → 清除本机阅读数据」可以删除这台 iPhone 中保存的 API Key、书籍、划线和小组件内容。卸载 App 也会删除本地阅读内容；重新安装后的首次启动会清理系统可能保留的旧 API Key。我们没有服务器，因此没有需要你联系我们才能删除的数据。
